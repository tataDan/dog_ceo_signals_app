# dogs_ceo_signals_app

This application allows the user to display photos of dogs. The user can either show random photos of dogs or display a set of photos of dogs of a selected breed.

It connects to the dog.ceo API to access dog photos and uses the "bloc_signals" and "bloc_signals_flutter" packages for state management.

The website for the dog.ceo API can be found [here](https://dog.ceo/dog-api/).

The repository for "bloc_signals" and "bloc_signals_flutter" can be found [here](https://github.com/RandalSchwartz/BlocSignal).

The pub.dev package for "bloc_signals" can be found [here](https://pub.dev/packages/bloc_signals). The pub.dev package for bloc_signals_flutter can be found [here](https://pub.dev/packages/bloc_signals_flutter).

This application has been tested on Linux, Windows, Chrome and Android. It has not been tested on iOS or macOS.
